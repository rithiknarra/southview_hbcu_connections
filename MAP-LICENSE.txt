This package renders actual OSM coordinates as SVG paths in Web Mercator.
The data snapshot was obtained from https://overpass-api.de/api/interpreter
on 2026-10-09. See MAP_DATA.timestamp for the upstream database timestamp.
Geographic extent: 33.70 to 33.78 latitude, -84.44 to -84.36 longitude.
Layers: streets, motorways, parks, and mapped university polygons.
Campus markers are reference locations, not navigation entrances.
The map is a bounded offline SVG snapshot, not a live tile service.
